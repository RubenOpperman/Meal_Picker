# 🍽️ DinnerSpinner

DinnerSpinner is a React web application that helps you decide what to have for dinner by letting you create a personal list of dishes and randomly selecting one for you.

The project was built as a practical way to improve my understanding of **React, state management, reusable components, and CRUD functionality** while creating something useful for my family.

## ✨ Features

* 🎰 Randomly select a meal from your dish collection
* ❤️ Mark dishes as favourites
* ➕ Add new dishes
* ✏️ Edit existing dishes
* 🗑️ Delete dishes
* 🔍 Filter dishes
* 💾 Store your dishes using Local Storage (coming soon...)
* 🏷️ Categorise dishes
* ⏱️ Store preparation times
* 📊 Set dish difficulty
* 🥗 Mark dishes as healthy or standard
* 📱 Responsive interface

## 🛠️ Built With

* **React**
* **JavaScript**
* **Tailwind CSS**
* **Vite**
* **Local Storage** (coming soon...)

## 🧠 What I Learned

This project helped me practise several concepts that are important when working with React:

* Managing state with `useState`
* Passing data and functions between components using props
* Rendering lists with `.map()`
* Updating arrays immutably with `.map()` and `.filter()`
* Creating reusable components
* Building and controlling modal components
* Handling form data
* Conditional rendering
* Working with objects and arrays
* Persisting application data with Local Storage
* Structuring a React application into separate components

One of the main things I wanted to understand better through this project was **how data flows through a React application** and how child components can trigger changes to state managed by a parent component.

## 🚀 Getting Started

### Prerequisites

You will need:

* [Node.js](https://nodejs.org/) installed
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/RubenOpperman/Meal_Picker.git
```

Navigate into the project:

```bash
cd YOUR-REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.
